## 关于本博客

这是一个基于 [hexo-theme-arknights](https://github.com/Yue-plus/hexo-theme-arknights) 主题构建的博客站点。该主题以游戏《明日方舟》为灵感设计，呈现出科技感与现代感并存的视觉效果。

## 主要特性

- ✨ 明日方舟风格的现代化设计
- 🌙 支持暗色/亮色主题切换
- 🔍 内置本地搜索功能
- 📊 支持 Mermaid 图表
- 💬 支持多种评论系统（Valine、Gitalk、Waline 等）
- 📈 支持字数统计和阅读时长
- 🎵 背景音乐播放
- 🎨 动态背景效果

## 快速开始

### 安装依赖

```bash
npm install
# 或者
cnpm install
```

### 本地预览

```bash
hexo server
```

访问 `http://localhost:4000` 即可预览博客。

### 生成静态文件

```bash
hexo generate
```

### 清除缓存

```bash
hexo clean
```

## 写作指南

使用 Hexo 命令创建新文章：

```bash
hexo new post "文章标题"
```

在文章的 Front-matter 中可以配置：

```yaml
---
title: 文章标题
date: 2026-02-04 12:00:00
tags:
  - 标签1
  - 标签2
category: 分类
---
```

使用 `<!-- more -->` 标记来分隔摘要和正文内容。
